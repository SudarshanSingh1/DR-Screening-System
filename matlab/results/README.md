# Experiment Results

Store lightweight, reproducible evaluation summaries and selected plots here.

## Guidelines

- Include confusion matrices, training curves, and per-class metrics.
- Keep files small and relevant.
- Do NOT commit large temporary outputs, raw training logs, or generated checkpoint files.
- Name results with the experiment date and a brief description (e.g., `2026-10-19_efficientnetb0_finetune_v3.md`).
